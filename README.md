# SinkoAdmin — Панель управления платформой Synco

Современная классическая административная панель для платформы Synco, созданная на **React 18 + TypeScript + Vite** с акцентом на высокую производительность, надежность и глубокую интеграцию со всеми 12 контроллерами `AdminController` бэкенда.

---

## 🎨 Дизайн и интерфейс
- **Цветовая палитра:** Глубокий темно-синий (`#070D18`, `#091322`, `#0E1C31`, `#1E3557`, `#2563EB`)
- **Типографика:** Google Fonts (*Outfit* для акцентных заголовков, *Inter* для таблиц и форм)
- **Аутентификация:** Прозрачный режим без принудительной авторизации/логина (встроен валидный токен администратора с ролью `Owner` для прямого доступа к API)
- **Интерактивный поиск:** Глобальный поиск по всей базе (клиенты, поставщики, заказы, товары) по горячей клавише `Ctrl+K`
- **Переключатель сред:** Мгновенное переключение между локальным бэкендом (`localhost:5206`) и облачным сервером Azure

---

## 📂 Функциональные разделы
1. **Обзор и KPI (`/`)** — ключевые метрики платформы (клиенты HoReCa, поставщики, заказы, подписки, предупреждения).
2. **Заявки на регистрацию (`/registrations`)** — рассмотрение входящих заявок, история звонков клиентов, назначение куратора, одобрение/отклонение.
3. **Организации (`/organizations`)** — реестр HoReCa и поставщиков, просмотр связанных сотрудников, заказов, адресов, приостановка и возобновление деятельности.
4. **Пользователи и персонал (`/users`)** — аккаунты организаций и сотрудники (курьеры, менеджеры, закупщики), создание пользователей, сброс паролей, смена ролей, блокировка.
5. **Подписки и тарифы (`/subscriptions`)** — управление подписками организаций (назначение, продление, заморозка) и конструктор тарифных планов.
6. **Заказы (`/orders`)** — мониторинг всех заказов платформы с историей изменения статусов и детализацией по позициям.
7. **Каталог и акции (`/catalog`)** — управление товарами поставщиков и модерация промо-акций (блокировка/разблокировка).
8. **Запросы изменений (`/requests`)** — утверждение смены ИНН (HVHH) и обновлений реквизитов компаний с diff-просмотром.
9. **Справочники каталога (`/settings`)** — управление категориями товаров, зонами доставки/регионами и сферами деятельности.
10. **Уведомления и шаблоны (`/notifications`)** — лог отправки системных сообщений и редактор шаблонов.
11. **Журнал аудита (`/audit`)** — подробная история всех критических действий администраторов (кто, когда, что изменил, IP, обоснование).

## 🚀 Запуск проекта

### Вариант 1: Запуск через bat-файлы (в один клик)
- **`start-local.bat`** — запускает панель с подключением к локальному бэкенду (`http://localhost:5206`).
- **`start-server.bat`** — запускает панель с подключением к облачному серверу Azure (`https://synco-h4etbseqg4h2ewcw.swedencentral-01.azurewebsites.net`).
- **`start.bat`** — интерактивное меню выбора режима.
- **`build.bat`** — сборка продакшен-бандла (`dist/`).

### Вариант 2: Запуск через терминал
```bash
# Установка зависимостей (один раз)
npm install

# Запуск с локальным бэкендом
npm run dev:local

# Запуск с серверным бэкендом Azure
npm run dev:remote

# Переключение режима без запуска сервера
npm run use:local
npm run use:remote
npm run backend:status
```

Админ-панель доступна по адресу: **http://localhost:5180**

## 🌐 Двуязычный интерфейс (i18n)
- **Языки интерфейса:** Армянский (🇦🇲 Հայերեն, по умолчанию) и Английский (🇬🇧 English).

## 🚢 Деплой в Azure и синхронизация с Git

### 1. Деплой в Azure App Service (`deploy.bat`)
- **Целевой адрес:** [https://sinkoadmin-gugab6amg9asejb4.swedencentral-01.azurewebsites.net/](https://sinkoadmin-gugab6amg9asejb4.swedencentral-01.azurewebsites.net/)
- **Команда:** Дважды кликните по **`deploy.bat`** или выполните в консоли:
  ```cmd
  deploy.bat
  ```
- **Что делает скрипт:**
  1. Выполняет чистую сборку проекта (`npm run build` -> папка `dist/`).
  2. Авторизуется в Azure через Service Principal (OAuth 2.0).
  3. Упаковывает файлы в оптимизированный ZIP (`dist/`, `server.js`, `web.config`, `package.json`, `scripts/`).
  4. Загружает архив на Kudu ZipDeploy endpoint.
  5. Проверяет и при необходимости устанавливает серверные зависимости (`express`, `compression`, `http-proxy-middleware`).
  6. Перезапускает инстанс Azure App Service и выполняет контрольный опрос health-check.

### 2. Фиксация и отправка в GitHub (`git-push.bat`)
- **Целевой репозиторий:** [https://github.com/ordyanh/SinkoAdmin.git](https://github.com/ordyanh/SinkoAdmin.git)
- **Команда:** Дважды кликните по **`git-push.bat`** или выполните в консоли:
  ```cmd
  git-push.bat
  ```
  Либо передайте сообщение коммита аргументом:
  ```cmd
  git-push.bat "Your commit message"
  ```
- **Что делает скрипт:**
  1. Инициализирует репозиторий Git и ветку `main` при первом запуске.
  2. Настраивает remote `origin` на целевой репозиторий GitHub.
  3. Показывает текущий статус измененных файлов.
  4. Добавляет все изменения (`git add -A`) с учетом `.gitignore`.
  5. Создает коммит с указанным (или сгенерированным) описанием.
  6. Выполняет `git push -u origin main`.
